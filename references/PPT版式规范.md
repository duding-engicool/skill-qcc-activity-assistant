# PPT版式规范

## 设计原则

**内容承载导向，不是演讲辅助导向。**

## 字数与信息密度

- **不设单页字数硬上限**，按版式分块承载
- 单页承载量参考:
  - 文字密集页: 可承载200-400字正文 + 1-2个表格/图
  - 表格密集页: 单表8-15行可单页承载
  - 图文混排页: 图占50-60%区域，文字100-200字
  - 封面/章节过渡页/致谢页: 字数少、留白多

**核心判断标准**: 去掉讲解，单看PPT是否能讲清楚这页要说什么。答否就加内容，答是就停。

## 字号档位

| 元素 | 字号 |
|------|------|
| 一级标题(页标题) | 24pt |
| 二级标题(章节内分项) | 20pt |
| 三级标题/强调短语 | 18pt |
| 正文/bullet | 14-16pt |
| 表格表头 | 12-14pt |
| 表格正文 | 10-12pt |
| 图注/数据标注 | 10pt |
| 页码/页眉 | 10pt |

## 配色(朴素工业风)

| 用途 | 颜色 |
|------|------|
| 主蓝(页眉条、表头、强调色) | #1F4E79 |
| 辅助灰(正文) | #595959 |
| 强调橙(关键数字/真因/目标值) | #ED7D31 |
| 警示红(不良项/风险项/未达成) | #C00000 |
| 浅灰底(表格隔行底色) | #F2F2F2 |

**禁止**: 渐变、3D阴影、霓虹色、纯黑底白字(除封面外)

## 排版

- 图文比不强求，按页面信息承载需要决定
- 图片: 原图PNG≥300dpi，禁直接截图模糊放大
- 表格: python-pptx原生表格，边框0.75pt灰线，表头主蓝白字，隔行浅灰底
- 段落间距1.15，bullet缩进0.5cm

**禁止装饰元素**:
- SmartArt
- 图标库
- 矢量插画
- 渐变形状
- 阴影特效
- 3D旋转
- 视差动画

## 动画

- 能不用就不用
- 必要时只用「淡入」或「擦除」
- **禁止**: 飞入/弹跳/旋转/缩放/路径动画
