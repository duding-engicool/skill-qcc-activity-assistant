# 讲稿撰写规范

## 单页讲稿结构

每页讲稿包含4个固定字段:

| 字段 | 说明 |
|------|------|
| 转折 | 与上页衔接的过渡语 |
| 念读 | 必须念出来的关键数据 |
| 判断 | 本页的核心结论 |
| 过渡 | 引向下页的衔接语 |

## 控时要求

| 页面类型 | 建议时长 |
|----------|----------|
| 常规页 | 60-120秒 |
| 数据密集页 | 可到180秒 |
| 表格页 | 可到180秒 |
| 封面/致谢 | 15-30秒 |

**总时长**: 落在目标±20%区间内可接受

## 数字念读规范

- 百分比: 读「百分之三十二点五」不读「32.5%」
- CPK: 读「CPK等于一点三三」
- 金额: 读「三百二十五万元」

## 转折语库

| 场景 | 转折语 |
|------|--------|
| 开场 | 各位评委、各位同事，大家好... |
| 进入新章节 | 接下来，让我们进入... |
| 数据说明 | 首先来看数据... |
| 得出结论 | 由此我们可以得出结论... |
| 过渡 | 这就引出了我们的下一个问题... |
| 结束 | 以上就是我们的汇报内容，感谢各位评委的聆听与指导！ |

## 关键数字高亮

以下数字必须高亮提醒发表人不能漏念:
- 现状值
- 目标值
- 实绩值
- 改善幅度
- 经济效益

## 讲稿示例

```
【P5: 现状把握】

【转折】接下来看现状把握部分。

【念读】
- 现状值为百分之五点二
- 不良类型Top3: 尺寸偏差百分之四十二、毛刺百分之二十八、表面划伤百分之十八

【判断】Pareto累积百分之八十八集中于尺寸偏差与毛刺，作为后续主攻方向。

【过渡】这就引出了我们的原因分析...

*[预计时长: 90秒]*
```
