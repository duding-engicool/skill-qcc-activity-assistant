# 发表前自查清单

## 自查时间安排

| 时间节点 | 检查内容 |
|----------|----------|
| 发表前7天 | 完成自查报告，所有❌项修复 |
| 发表前3天 | 完整试讲1次，控时 |
| 发表前1天 | 备份PPT(U盘+邮箱+云端) |
| 现场前1小时 | 试投影、试翻页器、试音 |

## 7大类检查项

### 1. 数据口径一致性
- [ ] Step3现状值 vs Step9实绩值是否同口径
- [ ] 样本量是否一致
- [ ] 层别字段是否一致
- [ ] 采集周期是否一致

### 2. 数字勾稽
- [ ] PPT、讲稿、主档案三处数值一致
- [ ] 现状值+改善幅度=实绩值
- [ ] 目标达成率计算正确

### 3. 图分辨率
- [ ] 所有插图≥300dpi
- [ ] 无截图模糊放大

### 4. 页数与控时
- [ ] 总页数≤100
- [ ] 总时长落在目标±20%
- [ ] 每页时长合理

### 5. 必备元素
- [ ] 封面齐全
- [ ] 圈情介绍齐全
- [ ] 致谢齐全

### 6. 版式规范
- [ ] 字号档位符合规范
- [ ] 配色符合朴素工业风
- [ ] 无禁用装饰元素(SmartArt/渐变/3D等)

### 7. 风险条目
- [ ] 结论有数据支撑
- [ ] 对策有PDPC预案
- [ ] R²/CPK数值合理

## 自查报告格式

| 级别 | 含义 | 处理 |
|------|------|------|
| ✅ | 通过 | 无需处理 |
| ⚠️ | 警告 | 建议修复 |
| ❌ | 不通过 | 必须修复 |

## 常见错误

1. **数据不一致**: 现状值在主档案和PPT中不同
2. **图片模糊**: 截图放大后模糊
3. **页数超限**: 超过100页
4. **装饰过度**: 使用SmartArt、渐变等
5. **讲稿缺失**: 没有讲稿或讲稿不完整
